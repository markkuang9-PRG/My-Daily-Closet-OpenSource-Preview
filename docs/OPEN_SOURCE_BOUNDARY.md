# Open Source Boundary

Safe to keep public:
- SwiftUI preview shell
- sample local wardrobe data
- generic image cleanup helper
- sanitized PWA migration checklist
- sanitized open-source strategy notes
- placeholder-only setup notes

Must stay private:
- production Next.js/PWA app source
- stylist ranking logic
- resale generation logic
- prompts and heuristics
- real backend config
- real user data
- service role keys, API keys, logs, screenshots with secrets
- beta tester notes and private launch plans
